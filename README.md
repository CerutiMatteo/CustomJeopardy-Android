# QuizBoard Android

A customizable Android quiz game inspired by the popular television game show **Jeopardy**, developed using **Embarcadero Delphi**.

The application provides a personalized quiz experience, adapting the traditional Jeopardy-style format into a custom Android game.

## 📱 About the Project

QuizBoard Android is a mobile application designed to bring a Jeopardy-inspired quiz experience to Android devices.

The project was developed as a customized interpretation of the original game, with its own design and gameplay implementation.

## ✨ Features

- Jeopardy-inspired quiz gameplay
- Customized game experience
- Interactive Android interface
- Mobile-friendly design

## 🛠️ Technologies

- **Programming Language:** Object Pascal
- **Development Environment:** Embarcadero Delphi
- **Framework:** FireMonkey (FMX)
- **Platform:** Android

## 📲 Compatibility

The application was developed for Android devices.

**Tested device:**
- Xiaomi 13T Pro

Compatibility with other Android devices has not been extensively tested.

## 🚀 Getting Started

### Requirements

- Embarcadero Delphi with Android development support
- Android SDK configured in Delphi
- An Android device or compatible emulator

### Installation

1. Clone the repository:
2. Open the Delphi project file (`.dproj`) in Embarcadero Delphi.
3. Select an Android target platform.
4. Build and deploy the application.
